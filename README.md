# Gestor de inventario con listas en Python

## Descripcion
Este proyecto permite administrar el inventario de una tienda
pequena mediante un programa de consola desarrollado en Python.

## Funciones
- Registrar productos y cantidades.
- Mostrar todos los productos.
- Buscar productos por nombre.
- Modificar cantidades disponibles.
- Eliminar productos.
- Mostrar la cantidad de productos registrados.
- Identificar el producto con mayor cantidad.
- Calcular las unidades totales del inventario.

## Requisitos
Tener Python instalado en el computador.

## Como ejecutar
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo main.py desde la terminal:

   python main.py

## Uso de las listas
Se utilizan dos listas paralelas: productos y cantidades.
Los elementos de ambas listas que tienen el mismo indice
corresponden al mismo producto.
